# Porting archive boundary

This directory is the explicit boundary for historical porting material. Its
original contents (the porting catalog, investigation reports, progress
tracker, and legacy native-UI screenshots) were retired during the 2026-09
deep-review remediation: none of them described the current `src/` tree, so
they were recorded as retired in `governance/topology/relocations.json` with
their baseline sha256 anchors and removed rather than re-published.

Retention policy: historical porting evidence may be re-added here only with
a topology retirement-entry reversal plus a preservation-ledger provenance
record; never as silent file drops.
